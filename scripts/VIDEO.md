# Soutenance Bloc 3

Depuis Ubuntu-Test, utiliser le checkout contenant la PR et les volumes du projet. Préparer la session Power BI Desktop sous Windows, activer si nécessaire les fonctionnalités de projet PBIP/PBIR, puis ouvrir le projet une première fois et actualiser le modèle. Le rapport contient une photographie des deux agrégats Gold, reconstruite à chaque exécution.

1. **Régression.** Dans un worktree séparé au commit rouge `27f22cf`, exécuter `python -m pytest -q data_platform/tests/integration/test_typed_value.py` avec Java 17+ et PySpark 4.1.0. Montrer les valeurs nulles inattendues. Au commit corrigé `59cfafe`, relancer le même test. Montrer la PR vers develop et la conversion en entier après résolution des noms.
2. **Kafka et Bronze.** Avec les quatre conteneurs habituels démarrés, afficher `curl -fsS 'http://localhost:18083/connectors?expand=status'` et `docker exec kafka-fema /opt/kafka/bin/kafka-topics.sh --bootstrap-server kafka-fema:9092 --list`. Vérifier les tâches RUNNING. Déclencher un événement CDC de démonstration avant la prise si nécessaire. Conserver le checkpoint associé au catalogue. Sur un catalogue entièrement neuf, définir `KAFKA_STARTING_OFFSETS=earliest` pour lire l’historique encore retenu. Une rétention expirée exige une restauration ou un snapshot cohérent.
3. **Silver, Gold et rapport.** Exécuter `bash scripts/run_video_demo.sh`. Montrer le nom de chaque job, la construction des deux tables dans build_gold_marts.py et leur lecture par le générateur du rapport. Sous WSL, le script demande à Windows d’ouvrir FEMA.pbip. Dans Desktop, cliquer sur Actualiser si nécessaire. Comparer les nombres par source avec Gold. Le fichier reste dans infrastructure/volumes/lakehouse/video/FEMA.
4. **SonarCloud.** Ouvrir le projet et sélectionner la branche ou PR analysée. Montrer le Quality Gate avec la date, puis les trois problèmes correspondant à la note C du retour pédagogique. Pour chacun, montrer la règle, la ligne, le risque concret, le traitement et le statut après analyse. Si la note a évolué, montrer aussi l’analyse historique. La commande `python scripts/sonar_video.py CLE_PROJET --branch NOM_BRANCHE` affiche les conditions et les vulnérabilités ouvertes de cette analyse. Les Security Hotspots disposent d’une vue de revue distincte. Afficher les fiches réelles à l’écran.
